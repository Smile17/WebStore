# Setup requirements
- Open your IDE, open terminal
- Run the commands to create and activate the virtual environment
  - py -m venv venv
  - venv\Scripts\activate
- Check installed libraries: py -m pip list
- Install packages from requirements.txt:
  - pip install -r requirements.txt

# Add new packages
- After developing you may need to add a new package
  - py -m pip freeze requirements.txt
